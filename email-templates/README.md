# Supabase auth email templates

Supabase sends the sign-up and password-reset emails itself, so these are pasted into the dashboard
(Authentication -> Emails -> Templates), not deployed with the app.

| Template | Subject | Body |
|---|---|---|
| Confirm sign up | Confirm your 365DaysJobsTeam account | confirm-signup.html |
| Reset password | Reset your 365DaysJobsTeam password | reset-password.html |
